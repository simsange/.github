# simsange/.github

> Organization-wide community health files and the org profile for the
> [simsange](https://github.com/simsange) organization.

The default `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md`, and
`CODE_OF_CONDUCT.md` here apply to every simsange repository lacking its own.

`profile/README.md` renders at [github.com/simsange](https://github.com/simsange).
